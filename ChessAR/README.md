# ♟️ Chess AR — Unity Augmented Reality Chess

**Chess AR** is a modern chess experience built with **Unity**, designed for both **classic 3D gameplay** and **Augmented Reality (AR)**.  
Play chess on a fully interactive board with smooth drag-and-drop controls, tile highlighting, captured-piece display, and the option to challenge an **AI-trained bot**.

---

## Gameplay Highlights

- **Interactive chessboard** with smooth movement and clean visual feedback
- **Tile hover highlight** to improve readability and player guidance
- **Drag-and-drop piece movement**
- **Captured pieces** are moved to the side of the board (instead of disappearing)
- **Captured pieces scaled down** for a clean “graveyard” layout

---

## Play Against an AI Bot

It includes an option to play against an opponent powered by **Artificial Intelligence**.

Features:
- AI bot trained to play chess
- Different difficulty levels (easy → hard) -> Work in progress
- Fast, responsive decision-making for smooth matches

---

## Augmented Reality Mode (AR)

This project is not only a 3D chess game — it is **adapted for Augmented Reality**.

In AR mode, you can:
- **Place the chessboard on a real-world surface**
- Play from different angles naturally by moving your device
- Enjoy a more immersive and realistic chess experience

Built using Unity’s AR ecosystem (AR-ready workflow).

---

## To run

1. Clone this repository:

2. Open in Unity:
   - Open **Unity Hub**
   - Click **Add project**
   - Select the project folder

3. Press **Play** to run the 3D version in the editor.

For AR mode:
- Build to a supported AR device (Android/iOS)
- Make sure AR packages are installed and enabled
